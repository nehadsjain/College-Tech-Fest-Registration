# College Tech Fest 2026 - Event Landing Page

## 📌 Project Overview

This is a responsive Event Landing Page developed as part of the CODSOFT Web Development Internship.

The website provides information about a college technical fest, including event details, schedule, registration, and contact information.

## 🚀 Features

- Responsive Navigation Bar
- Hero Section
- About Section
- Event Schedule
- Registration Form
- Form Validation using JavaScript
- Contact Section
- Google Maps Integration
- Smooth Scrolling
- Scroll Reveal Animations
- Responsive Design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
